# mTLS-Channel-with-PKI-
Защищенный канал с аутентификацией по сертификатам с динамической подписью трафика и SIEM-мониторингом

=== SRC ===

server.py - Серверная часть: приём защищённых подключений, проверка подписей, логирование

сlient.py - Клиентская часть: установка mTLS-соединения, отправка и проверка подписанных сообщений

pki.sh - скрипт развертывания PKI

crypto_utils.py - Криптографическая библиотека: загрузка ключей, подпись/проверка сообщений, проверка CRL

network_utils.py - Библиотека для передачи JSON-сообщений по SSL-сокету (фрейминг с префиксом длины)
