# mTLS-Channel-with-PKI-
Защищенный канал с аутентификацией по сертификатам с динамической подписью трафика и SIEM-мониторингом

=== SRC ===

crypto_utils.py - библиотека с функциями подтверждения подписи, самой подписью, загрузкой приватного и публичного ключей и проверкой сертификата на наличие в CRL
network_utils.py - библиотека с функциями отслыки/получения json-строки
server.py - скрипт сервера; запускается первым
