# mTLS-Channel-with-PKI-
Защищенный канал с аутентификацией по сертификатам с динамической подписью трафика и SIEM-мониторингом

=== SRC ===

server.py - Серверная часть: работает в режиме бесконечного прослушивания порта. Принимает mTLS-подключения, проверяет клиентские сертификаты (в том числе по CRL), читает подписанные JSON-сообщения, верифицирует подпись, отправляет подписанные ответы. Пишет структурированный аудиторский лог в JSON-формате.

сlient.py - Интерактивная клиентская часть. Подключается к серверу, выполняет взаимную TLS-аутентификацию, проверяет серверный сертификат. Можно вводить текстовые сообщения, которые автоматически подписываются и отправляются. Полученные ответы проверяются на целостность подписи. Все события фиксируются в локальном логе установка mTLS-соединения, отправка и проверка подписанных сообщений.

pki.sh - shell-скрипт для создания иерархии сертификатов: корневой CA, серверный сертификат, клиентские сертификаты (Alice, Bob, Mallory), а также CRL. После выполнения формирует каталог `pki/` с необходимыми файлами.

crypto_utils.py - Криптографическая библиотека. Содержит функции:

* sign_message() / verify_message() - подпись/проверка сообщений, проверка CRL.
  
* load_pubkey_from_cert() / load_privkey() - загрузка ключей,
  
network_utils.py - Библиотека для передачи JSON-сообщений по SSL-сокету (фрейминг с префиксом длины)
Содержит 2 функции: 

* send_json() / recv_json() - функции отсылки и приема сообщений, реализующие простой протокол фрейминга: 4 байта длины сообщения (big-endian) + тело JSON.
